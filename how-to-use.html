How to use TempConvert.

A practical walkthrough for converting measurements, switching units, copying results, and sharing a conversion.

1. Choose a conversion category

Open the converter and select a category from the category list, such as Temperature, Length, Weight, Volume, Speed, or Digital Storage. The available unit choices change to match that category.

2. Enter the number

Click or tap the input field in the left panel and type the value you want to convert. Use a number such as 25, 3.5, or 0. Use a decimal point for decimal values. The converter updates the result as you type.

3. Select the starting and target units

Use the first dropdown to choose the unit you already have. Use the second dropdown to choose the unit you want. For example, select Celsius as the starting unit and Fahrenheit as the target unit.

4. Swap the units

Tap the swap icon between the unit panels to exchange the source and target units. The same entered value is then interpreted using the newly selected source unit.

5. Copy the result

Use the Copy control beneath the result to copy the displayed value and unit. Paste it into a document, message, or other application as needed.

6. Share a conversion

Use the Share control to share a link to the current category and unit selection. Depending on the browser, you may be able to use the device share sheet or copy the link. Be aware that the input value and selected units may be included in the URL.

7. Save a favorite category

Use the Save control to keep a category in the browser’s saved preferences. This preference is stored locally on the device and is not synchronized to another browser or device.

8. Change the appearance

Use the theme control to switch between the available light and dark appearances. Your preference may be remembered in local storage.

Tips for reliable results

  • Check both unit labels before copying a result.
  • Check whether a gallon is US or Imperial.
  • Remember that month and year conversions are average approximations.
  • Fuel-economy units are reciprocal; lower L/100 km means better fuel economy.
  • Displayed values are rounded for readability. Verify critical calculations against authoritative references.
