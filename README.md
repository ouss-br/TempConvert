# TempConvert — Complete contact and policy build

Static website using plain HTML, CSS and JavaScript. No backend or database is required for the converter.

## Contact form delivery

The Contact page uses FormSubmit to forward form submissions to **bouraouioussama1@gmail.com**.
IMPORTANT: Before relying on the form, publish the site, submit a test message, and check the receiving inbox for FormSubmit's activation email. Confirm/activate the address using that email. Until activation, form delivery may not work. Test a second message after activation. If you prefer a different form provider later, update the contact form and privacy/cookie policies together.

The form collects full name, email address, enquiry type, optional page/category, and message. It uses required fields, basic browser validation, length limits, a honeypot field, and a privacy acknowledgement. It does not ask for a phone number or other unnecessary personal details.

- About, contact form, privacy policy, terms of use, cookie policy, FAQ, how-to-use guide.

## Before public launch

1. Replace every `https://YOUR-DOMAIN.example` placeholder in canonical links, sitemap, robots.txt, and the contact form's `_next` field with the exact deployed HTTPS domain.
2. Confirm the legal operator identity and applicable jurisdiction. Add any legally required operator name, postal address, registration details, and governing-law terms.
3. Verify the actual hosting provider's logs, retention, and privacy practices and update Privacy/Cookie pages accordingly.
4. Publish, submit the contact form once, activate the FormSubmit email from your inbox, then test again.
5. Test all form fields, navigation, unit conversions, mobile layout, and every page.
6. Check the website's network requests/cookies after deployment. The current project has no AdSense or analytics script. Update legal disclosures and configure any required consent platform before enabling them.
7. Verify conversion factors and calculations against authoritative references before using results in safety-critical work.
